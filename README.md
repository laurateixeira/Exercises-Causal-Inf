# Exercises for Prediction Under Intervention

This repository contains a collection of practical exercises on causal inference and prediction under interventions, using simulated data and R.

## Exercise 1 – Inverse Probability Weighting (IPW)

An introduction to causal inference using inverse probability weighting (IPW) to estimate the average treatment effect (ATE) in an observational study.

The exercise covers assumptions, propensity score estimation, covariate balance, and IPW estimation.
